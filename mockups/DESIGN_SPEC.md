## 01. 홈 (`mockups/01-home.png`)

### 헤더 물감 애니메이션 ★
진입 시 초록 헤더가 **위에서 아래로 쏟아지듯** 채워집니다.

```dart
TweenAnimationBuilder<double>(
  tween: Tween(begin: 0, end: 1),
  duration: const Duration(milliseconds: 1900),
  curve: const Cubic(0.33, 0.72, 0.24, 1),
  builder: (context, t, child) => ClipRect(
    child: Align(
      alignment: Alignment.topCenter,
      heightFactor: t.clamp(0.001, 1),
      child: child,
    ),
  ),
  child: _body(),
)
```

- **튕김(오버슈트) 금지.** 곧게 멈춥니다.
- 헤더 **내용도 면과 함께** 내려옵니다 (따로 페이드인 X).
- 목업에는 헤더 아래로 흘러내린 물감 방울 6개가 있습니다. Flutter 는 선택 구현 — 없어도 됩니다.

### 구성
1. 날짜 · 포인트 칩 · 프로필 (포인트 칩 → 포인트 내역)
2. "{이름} 님, 오늘도 한 바퀴 어떠세요?" + 연속 기록 칩(불꽃 아이콘)
3. **이번 주 화분** — 요일 7칸, 오늘은 초록 테두리 + 연초록 배경
4. **내가 만든 변화** — 탄소 감축량(큰 숫자) + "소나무 N그루" / 쓰레기·걸음·레벨 3칸 / "어떻게 계산했나요?" (왼쪽 정렬, 누르면 계산식 팝업)
   - 계수: 쓰레기 1kg → 탄소 **0.66kg**, 소나무 1그루 = 연 6.6kg 흡수 (`EcoMath` 와 일치)
   - 활동이 0건이면 0을 보여주지 말고 "30분만 걸어도 / 평균 300g·탄소 198g" 카드로 대체
5. **오늘의 환경 뉴스** — 카테고리 배지 + 출처·날짜, `>` 로 전체 뉴스
6. **지금 우리 동네는** — "오늘 N명이 활동했어요" (지역명 제외), 그룹 3개. 카드를 누르면 **팝업**으로 그룹 소개 + 가입하기

### 하단 내비
5칸, 가운데 **시작** 범프(88px 원, 초록 75px 안쪽 원).
홈 / 그룹 / (시작) / 내 활동 / 메뉴

## 02. 로그인·회원가입 (`mockups/02-auth-login.png`)

### 로그인
- 카드·마스코트 **없음**. 위쪽은 여백 + 큰 타이포
- 체크마크가 그려지며 등장 (`CustomPainter` + `PathMetric.extractPath`, 900ms)
- "걷는 만큼 깨끗해지는 동네" (17px) / "줍다행" (40px, w800, letterSpacing -1.4)
- 아래 흰 시트(라운드 32, 위쪽만) + **밑줄 입력**. 라벨은 12px w700 letterSpacing 1
- 비밀번호 재설정은 팝업

### 회원가입 3단계
진행 바(4px, 3칸) + "1 / 3"

1. **계정** — 이메일·비밀번호(8자 이상) + "이메일은 비밀번호를 다시 만들 때만 써요" 안내
2. **프로필** — "더 정확한 측정에 필요해요 / 걸음수와 칼로리를 계산하는 데 쓰여요"
   성별 2칸 + 나이·키·몸무게(휠 시트) + 지역(GPS 자동, 편집 불가)
   **건너뛰기** 있음
3. **닉네임** — 2~10자, 26px w800 입력. 아래 실시간 안내 한 줄
   - 빈 값: "한글·영문·숫자를 쓸 수 있어요" (info, 회색)
   - 중복: **"이미 사용 중인 닉네임이에요"** (error, 빨강)
   - 정상: "쓸 수 있는 닉네임이에요" (check_circle, 초록)
   - **그룹 피드 미리보기** — 입력한 이름이 실제 카드에 반영됨

## 03. 도착지 설정 (`mockups/03-destination.png`)

### 핵심: 지도를 움직여 도착지를 맞춘다
탭으로 찍는 방식이 **아닙니다.** 검색·목록도 없습니다.

- 도착 깃발은 **화면 중앙 고정**. 지도를 드래그해 위치를 맞춥니다
- 카메라가 멈추면(`onCameraIdle`) 중앙 좌표를 도착지로 확정하고 경로 재요청
- **현재 위치 핀과 도착 깃발이 겹치지 않게** 초기 카메라를 북동쪽으로 오프셋
  ```dart
  NCameraUpdate.scrollAndZoomTo(
    target: NLatLng(lat + 0.0016, lon + 0.0016), zoom: 15,
  )
  ```
  → 현재 위치는 왼쪽 아래, 도착 깃발은 오른쪽 위
- 오른쪽 위 **내 위치로** 버튼 (같은 오프셋으로 복귀)

### 마커
- 드래그 중이면 깃발이 살짝 뜨고 그림자가 커짐
- 말풍선 "약 N분 · N.Nkm" — 깃발 **위**에 붙음
- 마커 끝이 가리키는 타깃 점 표시

### 하단 카드
- 주소 + 근처 지명
- **정화 거점 N곳을 지나요** (초록 재활용 아이콘)
- **위험 구간을 지나지 않아요** / 지나면 "약 120m를 지나요" (경고 아이콘, 갈색)
  - "산업지대" → **"위험 구간"** 으로 용어 변경
- 상태별 CTA: 드래그 중 "도착지를 맞추는 중" / 계산 중 "경로 계산 중" / 준비됨 "이 위치에서 시작"
- 인천시 밖이면 "인천시 안에서만 플로깅할 수 있어요", 300km 초과면 "목적지가 너무 멀어요"

## 04. 플로깅 활동 (`mockups/04-plogging-activity.png`)

### 플로깅 활동 규칙 (첫 진입 자동 + ? 버튼)
같은 시트를 씁니다. 첫 진입이면 제목 "첫 플로깅을 시작할게요", 버튼 "시작하기".

4개 항목:
1. **활동 범위** — 인천시 안에서만, 목적지는 300km 이내
2. **정화 거점과 위험 구간** — 정화 거점은 쓰레기가 많이 나오는 곳(초록 핀), 위험 구간은 공사장·차도처럼 걷기 위험한 곳
3. **쓰레기 촬영** — 주울 때마다 한 개씩
   > ⚠️ **빨강 강조**: "주운 쓰레기는 활동 중에만 촬영할 수 있으며, 종료 후에는 활동 인증샷만 촬영이 가능해요."
4. **활동 종료 및 포인트 획득** — "활동을 종료하면 걸음·거리·수거량으로 **포인트**와 **경험치**를 얻을 수 있어요. 정산 화면에서 촬영하는 **인증샷**은 그룹 채팅방에 올라가며, 선택사항이에요. 나중에 내 활동에서 따로 첨부할 수도 있어요." (굵게 표시한 3개 강조)

### 기록 카드
- **화면 폭을 거의 꽉 채웁니다** (좌우 12px). 40+16 처럼 잘라내지 마세요
- 위: GPS 상태 칩 → **활동 시간 라벨** → 큰 타이머(44px w800) 순서
- 아래: 걸음 · km · 수거 3등분 타일

### 수거 타일 펼침 애니메이션 ★
수거 타일을 누르면 **걸음·km 타일을 덮으며** 넓어집니다.

```
duration 520ms, curve Cubic(0.32, 0.72, 0, 1)
접힘 높이 66 → 펼침 140
```

- 걸음·km 는 **투명도만** 낮추고(190ms), 접힐 땐 지연 없이 바로 돌아옴
- 타일 안 내용은 고정 폭으로 띄워두고 **바깥 폭만** 깎이게 (매 프레임 재배치 금지 — 끊김 원인)
- 헤더는 방향이 바뀌는 대신 접힘/펼침 두 버전이 **교차 페이드**
- 종류별 5칸은 선이 지난 뒤 나타남
- 좁은 칸에서 "플라스틱"이 여러 줄로 깨지지 않게 `FittedBox` + `maxLines: 1`

### 카메라 / 종료 — 2단 터치 ★
```
[선택 전]  카메라        |  종료
[한 번 누름] 촬영하기      |  종료
            한 개씩 찍기
[한 번 더]  → 카메라 실행
```
- 시작 시 **촬영이 이미 커진 상태** (한 번만 더 누르면 바로 카메라)
- 커진 쪽 폭 비율 **1.85 : 1**, 전환 420ms
- 축소된 쪽은 라벨 가운데 정렬, 커진 쪽은 아이콘 + 왼쪽 정렬
- 종료에는 부제 없음 (`subtitle` 은 `String?`)

### 지도
- 지나온 경로는 그리지 않고 **현재 위치 → 목적지 구간만** 초록 선
