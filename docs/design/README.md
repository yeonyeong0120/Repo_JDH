# 디자인 시안 원본 (Claude 디자인 캔버스)

2026년 9월 28일에 받은 디자인 캔버스 내보내기 링크에서 꺼낸 원본이다.
그 링크에는 접근 토큰이 붙어 있어 만료되면 다시 열 수 없으므로 여기에 보관한다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `startline-flow-export.dc.html` | 화면 40개의 실제 소스. 시안의 본체다. |
| `plogo-activity-menu.canvas.dc.html` | 캔버스 인덱스. 위 파일에서 어떤 화면을 어떤 상태로 배치했는지 정의한다. |
| `support.js` | 캔버스 런타임. 두 파일이 브라우저에서 렌더되려면 필요하다. |

세 파일 모두 번들에서 꺼낸 그대로이며 수정하지 않았다.
원본 번들(9.5MB)은 나머지 용량이 전부 Tabler 아이콘 폰트와 React CDN 사본이라 보관하지 않았다.
같은 이유로 이 파일들을 브라우저에서 열려면 인터넷 연결이 필요하다.

## 캔버스 구성 (3개 섹션 32컷)

- 내 활동 13컷: 기록·뱃지·그래프 탭, 뱃지 팝업(획득/미획득), 그래프(주간/월간/누적),
  전체 활동, 활동 기록 상세, 공유 팝업, 챌린지, 자주 가는 코스, 인증샷 모음집
- 메뉴·리워드 11컷: 메뉴, 프로필, 몸무게 선택, 포인트 내역, 포인트 샵, 상품 상세,
  구매 확인, 구매 완료, 쿠폰함, 쿠폰 사용, 사용 완료 토스트
- 설정·계정 8컷: 설정, 알림, 도움말, 로그아웃, 탈퇴 안내(동의 전/후), 탈퇴 최종 확인, 탈퇴 완료

캔버스 인덱스의 `<dc-import>` 속성이 각 컷의 상태를 지정한다.
예를 들어 `ov="buy"`는 구매 확인 팝업이 열린 상태, `bd-sel="3"`은 획득한 뱃지,
`bd-sel="14"`는 미획득 뱃지다.

## 화면 키

`startline-flow-export.dc.html`의 `NAMES`에 키와 한글 이름이 정의되어 있다.
`home`(홈), `activity`(내 활동), `menu`(메뉴), `shop`(포인트 샵), `product`(상품 상세),
`coupons`(쿠폰함), `points`(포인트 내역), `profile`(프로필), `records`(전체 활동),
`record`(활동 기록 상세), `challenge`(챌린지), `courses`(자주 가는 코스),
`gallery`(인증샷 모음집), `settings`(설정) 등 40개다.

## 기준값

- 화면 크기 390 x 890, 폰트 Pretendard
- 강조색 `#E9FF6A`, 차콜 `#2A2F2C`, 보조 텍스트 `#8A8F8B`, 캔버스 배경 `#E4E7E9`
